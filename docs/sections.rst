===========================
📂 Sections du Projet
===========================

Cette page regroupe les différentes parties essentielles du projet
``.github_action`` et explique leur rôle.

---------------------------
📁 Structure principale
---------------------------

- ``.github/`` — workflows, templates, sécurité, contribution.
- ``docs/`` — documentation officielle.
- ``assets/`` — ressources visuelles.
- ``README.md`` — présentation générale du projet.
- ``CHANGELOG.md`` — historique des versions.

---------------------------
⚙️ Workflows GitHub Actions
---------------------------

Les workflows se trouvent dans :

``.github/workflows/``

Ils permettent :

- l’intégration continue (CI)
- la validation des fichiers
- l’automatisation des tâches
- la génération de releases

---------------------------
🧩 Templates GitHub
---------------------------

- Issues : ``.github/ISSUE_TEMPLATE/``
- Pull Requests : ``.github/PULL_REQUEST_TEMPLATE/``

Ces fichiers assurent une contribution propre et standardisée.

---------------------------
📘 Documentation
---------------------------

La documentation est organisée dans ``docs/`` et comprend :

- ``index.md`` — page d’accueil
- ``navigation.rst`` — plan global
- ``guides.rst`` — guides pratiques
- ``CHANGELOG.md`` — historique
